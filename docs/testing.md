# Проверки

## Общая команда

```sh
python scripts/check.py
```

Работает из любого каталога; на Windows также доступен scripts/check.ps1.
Зависимости: Go 1.24, Node.js 22+, Python 3.10+; pip/npm-установка не требуется.
Команда выполняет Go-тесты, go vet, сборку сервера во временный каталог,
синтаксис JS, сравнение меню JSON/JS, Python-тесты импортёра и аудит каталога.
Любая ошибка даёт ненулевой итоговый код. Остальные шаги выполняются,
чтобы получить полный список ошибок.

CI выполняет ту же команду на Windows и Linux.
Сборка Docker и браузерная приёмка в эту команду не входят.

## Изоляция

Ключи и iiko_config.json для автопроверок не нужны. Сетевые Go-тесты используют
локальные httptest-серверы: это offline относительно iiko, но не запрет loopback.
Ограничения sandbox на сокеты или временные каталоги могут помешать проверкам.
Фиксируйте такие ограничения отдельно от ошибок приложения.

Запускайте только discovery для test_import_menu.py. tools/test_order.py —
живая утилита, а не unit-тест. Проверки не запускают сервер с боевой конфигурацией.

## Контракт меню

node scripts/check-menu.cjs сверяет ID, iiko ID, цены, категории и отсутствие
дубликатов у доступных позиций JSON и JS. Go-тест TestMenuCatalogConsistency
проверяет соответствие этих позиций серверному каталогу по обоим ID и цене.
Дополнительные серверные позиции допустимы. Локальный аудит импортёра проверяет
UUID, цены, категории и наличие фотографий.

## Ручная приёмка UI

Проверяйте мобильный и desktop viewport, а также ширины около 1024 px:
- категории, изображения, пустую корзину, добавление/удаление, суммы и восстановление;
- доставку и самовывоз, телефон и адрес, ошибки полей;
- отправку через mock API: успех, pending, отказ, timeout и повторную попытку;
- закрытие шторки, клавиатуру, фокус, прокрутку и отсутствие горизонтального overflow;
- WhatsApp-бронирование: сообщение заполняется, но без подтверждения ресторана
  не показывается как подтверждённая бронь.

Не отправляйте реальные заказы для проверки UI без согласованного живого теста.
Отдельного автоматизированного браузерного стенда пока нет.

## Как сообщать результат

Укажите команду, успешные и неуспешные шаги, ограничения среды и ручные проверки.
Не объявляйте весь набор успешным по exit code последней команды в shell.
Боевой тест и развёртывание проверяются отдельно по operations.md.
