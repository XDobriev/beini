# Архитектурные решения

идемпотентность, источник каталога, оплата, схема заказа в зале.
Обычная правка или выбор имени переменной не требует ADR.

Файл: NNNN-короткое-название.md.
Содержание: дата, статус (предложено/принято/заменено), контекст, решение,
альтернативы, последствия, ссылки на реализацию и проверки.
