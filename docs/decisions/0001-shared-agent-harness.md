# 0001: Общие инструкции и проверки для агентов

Дата: 1 ноября 2026. Статус: принято в рамках настройки harness.

Контекст: AGENTS.md, GEMINI.md и CLAUDE.md содержали разные инструкции.
Правила дизайна и ограничения живых тестов получались разными в разных клиентах.
Команды проверок выполнялись вручную.

Решение:
- Общая инструкция — AGENTS.md, подробности — тематические документы docs/.
- GEMINI.md и CLAUDE.md направляют к общей базе; правила не копируются.
- Общий runner — Python standard library, доступный на Windows и Linux.
- CI запускает тот же runner, не подключая ключи ресторана.
- Расхождение каталогов блокируется проверками JSON/JS/Go.
- Крупная незавершённая работа передаётся через docs/tasks/.

Альтернативы: независимые инструкции каждому агенту (риск расхождений);
только персональные настройки (не передаются с Git); npm как runner
(добавляет отдельную систему зависимостей без необходимости).

Последствия: нужен Python, Node и Go; импорт инструкций следует проверить
в конкретном клиенте. Loopback нужен Go mock-тестам.
Единая генерация серверного каталога остаётся отдельной задачей.
