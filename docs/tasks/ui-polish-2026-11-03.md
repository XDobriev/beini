## Цель и критерии приёмки

Устранение визуальных шероховатостей витрины по замечаниям владельца:
- Убрать кнопку «Войти как тестировщик» из гостевой корзины и системных ответов 403.
- Выровнять верхнюю плашку о разработке с границами общего контейнера сайта (1280px).
- Синхронизировать высоту (48px) и радиус скругления (6px) строки поиска и кнопки «Очистить», сбросить WebKit searchfield стили.
- Удалить отображение служебного времени проверки меню из-под поиска и из корзины.
- Обновить дизайн блока акции «День рождения в Бейни» (уйти от агрессивной сплошной красной заливки к сдержанному стилю бренда с бейджем).
- Исправить сетку фактов в Hero: перевести на симметричную сетку 2×2, чтобы «Кабинки без депозита» не выпадали на вторую строку в одиночестве.
- На мобильных устройствах сделать корзину полноэкранной (`100dvh`) с фиксацией шапки и крестика (`sticky`).
- Полностью удалить секцию Instagram со страницы.

- Сохраняется Vanilla JS / CSS без добавления runtime-библиотек.
