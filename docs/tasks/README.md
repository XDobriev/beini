# Передача задач между агентами

Создавайте файл для крупной начатой задачи по TEMPLATE.md.
Новый агент читает AGENTS.md и этот файл, проверяет актуальный Git status/diff
и продолжает с указанного шага. История чата не должна быть обязательной.

Указывайте ветку и исходный commit, критерии приёмки, затронутые файлы,
что сделано и осталось, точные результаты проверок и блокеры.
Не сохраняйте секреты, персональные данные и полные протоколы чата.
Используйте относительные пути, пригодные на другом компьютере.

Обновляйте при значимом изменении состояния и перед передачей.
По завершении отметьте итог и commit/PR; приоритеты остаются в ../roadmap.md.
Для небольшой законченной правки отдельный файл не нужен.

Актуальный объединённый результат: [интеграция первых трёх задач](integration-2026-11-01.md).
