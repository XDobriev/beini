## Ошибки публикации и исправления

Первая попытка около 22:12 получила 203/EXEC Permission denied. Распаковка
`tarfile` с `filter='data'` под umask077 оставила каталоги нового релиза с 0700.
Бинарник имел 0755, но сервис не мог пройти через bin/. Проверка прав до остановки
не была выполнена — ошибка подготовки релиза. Автоматический откат вернул
symlink, но старт прежней версии ограничил StartLimit. После reset-failed
прежний сервис восстановлен; содержимое журнала не изменилось и оставалось пустым.

Права только нового релиза приведены к intended manifest: каталоги/binary0755,
файлы0644. Ошибка воспроизведена через `runuser -u beini -- test -x`, затем
проверка прошла. Добавлены обязательные preflight чтения всех manifest-файлов
и исполнимости binary от имени beini. В 22:16 релиз 4f2ab2b успешно запущен.
Регламент обновлён, повторный инцидент с правами не наблюдался.

Браузер с прежним кэшем затем показал 210 карточек, хотя API отдавал 251:
старый app.js не знал три новых раздела. Исправлены обе версии JS-ссылок в HTML,
добавлен Cache-Control: no-cache для перепроверки HTML. Тест
TestGuestHTMLRequiresRevalidation показал RED→GREEN. Финальный релиз 8651622
запущен в 22:28:53; тот же браузер после обычного reload показал 251/11.
