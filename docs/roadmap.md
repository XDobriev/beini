# Roadmap BEINI

Обновлено 1 ноября 2026. Текущий объём и инфраструктура определены
[подтверждёнными вводными владельца](confirmed-context-2026-11-01.md).
Показ руководству — 2 ноября после обеда, точное время не задано.
Приоритет: доставка, затем самовывоз, затем заказ за столом.
Прежний срок «до 11:00» в [плане запуска](launch-plan-2026-11-02.md)
больше не актуален; его технические замечания сохраняются как исходный аудит.

| Приоритет | Работа | Статус | Критерий завершения |
|---|---|---|---|
| P0 | Корректное отображение и отслеживание pending | Открыто | Гость и смена различают ожидание, подтверждение и отказ; есть итоговый статус |
| P0 | Повторные попытки и рестарт | Открыто | Потеря ответа и перезапуск не создают повторный заказ; неопределённость сверяется с iiko |
| P0 | Уведомления администратору | Только спецификация/план | Подтверждение iiko, ожидание и ошибка доходят в закрытую группу; сбой Telegram не мешает заказу |
| P0 | Поиск по всему меню | Не реализовано | Гость находит блюда независимо от категории; проверены пустой запрос и отсутствие результатов |
| P0 | Синхронизация с iiko | Архитектура обсуждается | Согласованы источник блюд, цен и стоп-листа, обновление и поведение при сбое; затем пройдена проверка |
| P0 | Окружение показа и приёмка | Требует решения | Согласован способ доступа к Go API; проверены статика, заказ и уведомление с сотрудником |
| Следующий этап | Заказ в зале по QR | Исследование | Выбрана схема стола и iiko; касса различает зал и доставку; пройдена приёмка |
| Техническая основа синхронизации | Единый источник меню | Частично | Проверки согласованности есть; ручное дублирование Go-каталога устранено |

Публичная витрина находится на GitHub Pages, API запущен только локально.
Размещение на имеющемся VPS Timeweb не согласовано. Дополнительные настройки
инфраструктуры и создание реальных заказов требуют соответствующего поручения.
Условия, зона, тариф и минимальная сумма доставки требуют уточнения;
отсутствующие значения нельзя подменять бесплатной доставкой.

## Основа разработки

Общие инструкции, карта документации, единая команда проверок и конфигурация CI
добавлены. Успешность CI подтверждается запуском workflow в GitHub после push;
наличие YAML само по себе не является результатом проверки.
При синхронизации нельзя трактовать сбой получения стоп-листа как пустой стоп-лист.
До автоматизации нужно исправить этот риск в импортёре.
