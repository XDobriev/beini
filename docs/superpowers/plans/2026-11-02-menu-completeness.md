# Полнота и корректность меню BEINI — предлагаемый план

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Статус:** владелец разрешил реализацию 2 ноября 2026; локальное исправление
подготовлено, независимое ревью и итоговая проверка завершены. Обычные блюда/напитки,
завтраки, соусы и гарниры включены; ФИРДАУС/банкет/служебные/упаковка/допы исключены.
Отдельное уточнение: NEW сохранить скрытыми до нового меню. Корзина модификаторов
не реализуется. Состояние и evidence — в документе задачи.

**Goal:** Гость видит весь согласованный ассортимент BEINI и заказывает именно
указанный товар iiko по правильной цене, с отдельным учётом временных стопов.

**Architecture:** Сохранить редакционный seed для подтверждённых товаров,
фотографий и текстов, обновление цены/наличия через существующий v3 worker.
Ввести проверяемую сверку соответствия карточек источнику; новые ID сначала
попадают в отчёт кандидатов. Не ослаблять ограничения размеров/открытых цен/
модификаторов ради количества карточек.

**Tech Stack:** Go 1.24+, Python 3.10+, Node.js 22+, HTML/CSS/Vanilla JS.

**Spec:** [диагностика и реестры](../../tasks/menu-completeness-2026-11-02.md).
Это основание предложения, не утверждённый дизайн новой корзины модификаторов.

## Global Constraints

- Сохранить HTML/CSS/Vanilla JS без runtime UI-библиотек и Tailwind CDN.
- Гостевые тексты на русском; диагностика не входит в гостевой checkout.
- Сервер сам определяет цены и названия; не доверять значениям из браузера.
- При обновлении меню согласовать JSON, JS и Go-каталог.
- Стопы не превращать в редакционный `available:false`; не снимать прежние запреты автоматически.
- Новая ветка/worktree уже подготовлены: codex/menu-completeness от e9e1521.
- Не коммитить и не публиковать без отдельного поручения владельца.
- Не менять настройки iiko/DNS/VPS/Nginx и не создавать реальные заказы.
- Секреты и машинные пути не хранить в Git; чужой документ и журнал №12540 сохранить.

## Варианты и рекомендация

1. **Поэтапное исправление (рекомендуется):** сначала правильные 35 карточек,
   затем согласованное расширение обычными товарами и отдельная поддержка
   сложных позиций. Каждая стадия проверяется независимо.
2. **Полная сборка витрины из iiko сразу:** требует утверждённого исключения
   служебных товаров, новых категорий, обработки отсутствующих фото, проверки
   единиц/порций и модификаторов. Технический допуск 303 продуктов ещё не является
   таким утверждением; этот вариант пока нельзя безопасно применить.

Рекомендация не считается выбором владельца. Начать исправление можно после
решения о составе и подтверждения привязок; подготовка отчёта уже закончена.

## Review Focus

- UUID существует, но указывает на другой товар: не допускать сохранение цены/названия от разных блюд.
- Совпадающие имена с разными объёмами/порциями: не объединять разные productId и не выбирать первый автоматически.
- Название iiko исправили косметически: требовать сверку, не считать произвольное строковое различие доказанной подменой.
- Правильный товар временно в стопе: карточка остаётся в каталоге, checkout блокируется; выход из стопа возвращает только наличие.
- Новая категория/нет фото: утверждённый товар не должен молча пропадать из frontend-фильтра.

## Отдельное решение: сложные позиции

Шесть открытых цен — либо фиксированная согласованная порция/цена во внешнем
меню отдельным поручением, либо явное исключение из online checkout. Нельзя
продавать четыре супа по 5 ₽ из-за удаления проверки openPrice.

Четыре продукта с modifierGroups — отдельный дизайн заказа: выбор ID,
min/max/default, расчёт доплат на сервере, DTO, сохранённая попытка и повторы,
стопы модификаторов, точный payload iiko. Для соков выбор обязателен. Не дробить
модификаторы на независимые блюда автоматически. Этот план не утверждает
реализацию поддержки модификаторов; после выбора нужен отдельный контракт и план.

## Критерий завершения будущего исправления

Каждый утверждённый товар виден в поиске/категории, соответствует своему iiko
UUID и порции, имеет серверную цену и актуальное наличие. Нет молчаливо
пропавших утверждённых ID и доступных карточек с чужой привязкой. Для каждого
исключения из внешнего меню зафиксирована проверяемая причина. Текущая
диагностика этих изменений не выполняла.
