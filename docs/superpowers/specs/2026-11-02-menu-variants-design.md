# Варианты порции в меню

Согласовано владельцем в чате 2 ноября 2026: одинаковое блюдо с разным весом
или объёмом показывается одной карточкой; разные вкусы остаются отдельными.

Варианты и цены видны кнопками внутри карточки. Выбор меняет цену и товар,
который добавится в корзину. Корзина хранит отдельные исходные ID и названия
порций, позволяет одновременно заказать несколько вариантов и переживает refresh.
Стоп-лист и подтверждение изменившихся цен действуют на каждый товар отдельно.
Недоступный выбранный вариант не заменяется другим незаметно для гостя.

## Подходы

Выбран подход: редакционные группы существующих товаров iiko на витрине.
Группы задаются явно в JSON, передаются API и статическим экспортом. Цена,
доступность и кассовый ID остаются у исходных товаров. Автоматическое слияние
по похожим названиям исключено.

Окно выбора добавляет лишний шаг для двух порций; пока не используется.
Встроенные размеры/модификаторы iiko требуют другого контракта заказа;
их поддержка в это изменение не входит.

Начальный набор: 19 лимонадов, 8 варений и 2 вида мёда (58 товаров → 29 карточек).
Неподтверждённые миллилитры не добавляются. HTML/CSS/Vanilla JS и существующие
токены сохраняются; кнопки не меньше 44 px, доступны с клавиатуры.
Поиск учитывает общее название и названия всех вариантов, скрытые NEW не раскрывает.
Публикация и реальные заказы в задачу не входят.
