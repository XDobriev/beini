## Порядок действий в пятницу

### Этап 1. Подготовка перед тестом (1 минута)
1. Подключите ноутбук или телефон к Wi-Fi ресторана или мобильному интернету.
2. Подойдите к кассовому терминалу iikoFront. Убедитесь, что:
   * Терминал включен и программа **iikoFront** запущена.
   * Открыта кассовая смена (если смена закрыта или касса спит, сервер iikoCloud возвращает статус `TerminalGroupDisabled`).
3. Предупредите администратора/кассира (Амину):
   > *«Я сейчас с сайта отправлю тестовый заказ доставки на 0 ₽ с пометкой "ТЕСТ", чтобы проверить, как касса принимает интернет-заказы»*.

---

### Этап 2. Отправка тестового заказа

У вас есть два способа отправки теста:

#### Способ 1. Прямо через браузер (наиболее эффектно для демонстрации Амине):
1. В терминале запустите сервер:
   ```bash
   go run ./cmd/server
   ```
2. Откройте в браузере `http://localhost:8080`.
3. Откройте `http://localhost:8080/demo` и нажмите **«Отправить тестовый заказ»** (или соберите корзину на главной и нажмите «Оформить заказ»).

#### Способ 2. Быстрый консольный тест через Go:
В терминале запустите:
```bash
go run ./cmd/test-order
```
*(Или через Python: `python test_order.py`)*

Что делает скрипт в этот момент:
1. Авторизуется по защищенному протоколу iiko API v2 и получает JWT-токен.
2. Формирует JSON-заказ типа **Самовывоз** (`deliveryPickUp`) с нулевой суммой.
3. Указывает имя гостя: **`ТЕСТ САЙТА (Хамзат)`** и телефон `+7 (920) 482-77-77`.
4. В комментарии передает: `★ ТЕСТОВЫЙ ЗАКАЗ С САЙТА ★ Проверка связки сайта и кассы iikoFront. Не готовить!`.
5. Отправляет запрос в метод `POST /api/1/deliveries/create` и выводит `correlationId` и статус очереди.

### Этап 3. Фиксация результатов на кассе iikoFront (Критерии успеха)

1. **Звуковое оповещение:**
   * Кассовый терминал издает характерный звуковой сигнал входящего интернет-заказа.
2. **Экран терминала:**
   * На кассе откройте вкладку **«Доставка»** (или «Банкеты/Резервы»).
   * В списке должна появиться новая карточка:
     * Гость: **ТЕСТ САЙТА (Хамзат)**
     * Номер телефона: **+7 (920) 482-77-77**
     * Комментарий с предупреждением: *«★ ТЕСТОВЫЙ ЗАКАЗ С САЙТА ★»*.
3. **Печать на кухонный термопринтер:**
   * Если на терминале настроена автоматическая печать сервисных чеков доставки, на кухне или баре сразу распечатается сервисный чек.

---

### Этап 4. Отмена тестового заказа (30 секунд)
Чтобы заказ не висел в смене и не попал в кассовый отчет:
1. Нажмите на экране терминала на созданный заказ.
2. Выберите действие: **«Отменить заказ»** (или «Отказ»).
3. В списке причин выберите: **«Тестирование / Обучение»**.
4. Заказ исчезает, смена остается чистой.
