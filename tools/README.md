# Служебные инструменты BEINI (`tools/`)

В этом каталоге собраны вспомогательные Python-скрипты для интеграции с iikoCloud, тестирования кассовых эндпоинтов и обработки медиаресурсов ресторана.

> [!CAUTION]
> **Внимание к кассовому контуру iikoFront:**
> Часть скриптов взаимодействует с реальным боевым сервером iikoCloud и кассовым терминалом ресторана. Перед запуском любого скрипта внимательно ознакомьтесь со статусом **«Создаёт ли реальный заказ»** в таблице ниже.

---

## Детальное описание каждого скрипта

### 0. `import_menu.py` — Управляемый импортёр, аудитор и валидатор меню BEINI
* **Назначение:** Реализует полностью поддерживаемый процесс обновления меню сайта из кассовой номенклатуры iikoCloud:
  1. **Zero Live Dependency:** Сам сайт не зависит от live-запросов к iiko и работает автономно от локального каталога `data/menu_catalog.json` и `js/menu-data.js`.
  2. **Безопасность ключей:** Ключи считываются из `iiko_config.json` (в `.gitignore`) или переменных окружения. В исходный код ключи не попадают.
  3. **Защита от случайного запуска:** Без явной команды сетевые запросы не отправляются.
  4. **Строгая валидация:** Каждое отображаемое блюдо обязано иметь:
     - `iiko ID` (валидный UUID v4);
     - цену (число > 0);
     - категорию (привязка к одной из 8 категорий сайта);
     - существующую картинку (физически проверенную на диске).
  5. **Структурированный отчёт:**
     - **Добавленные:** новые блюда в iiko;
     - **Скрытые / удалённые:** позиции, удалённые в iiko;
     - **Недоступные:** блюда в стоп-листе кассы или с 0 ценой;
     - **Позиции без фото/категории:** блюда, требующие контента.
* **Зависимости:** Python 3.10+, только стандартная библиотека.
* **Создаёт ли реальный заказ:** ❌ **НЕТ.** Только чтение номенклатуры и стоп-листов.
* **Команды запуска:**
  ```bash
  # 1. Быстрая валидация локального каталога (без сети)
  python tools/import_menu.py --check

  # 2. Сверка с локальным дампом номенклатуры в режиме dry-run (без сохранения)
  python tools/import_menu.py --from-file iiko_nomenclature.json

  # 3. ЯВНАЯ КОМАНДА: получение свежей номенклатуры из iikoCloud (dry-run)
  python tools/import_menu.py --fetch

  # 4. Применение изменений в data/menu_catalog.json и js/menu-data.js
  python tools/import_menu.py --fetch --apply

  # 5. Сохранение отчета в файл
  python tools/import_menu.py --check --report menu_report.txt
  ```

### 1. `test_order.py` — Отправка тестового заказа на терминал кассы
* **Назначение:** Отправляет боевой тестовый заказ (позиция «Латте», 250 ₽, самовывоз) через iikoCloud API (`/api/1/deliveries/create`) непосредственно в очередь кассового терминала `iikoFront` ресторана BEINI.
* **Зависимости:** Python 3.10+, стандартная библиотека (`json`, `sys`, `os`, `urllib`). Требует наличия `iiko_config.json` в корне проекта или переменной `IIKO_CONFIG_PATH`.
* **Создаёт ли реальный заказ:** 🚨 **ДА! СОЗДАЁТ РЕАЛЬНЫЙ ЗАКАЗ НА КАССЕ.**
  * Заказ попадает во вкладку «Доставка / Самовывоз» на терминале iikoFront.
  * При включенном сервисном принтере может распечататься чек на кухне или кассе.
  * Заказ требует ручной отмены кассиром или администратором в iikoFront!
* **Безопасный способ запуска:**
  * Запускать **только** во время согласованного тестирования с персоналом ресторана:
  ```bash
  python tools/test_order.py
  ```
* **Предостережение:** ❌ **Никогда не запускать по расписанию (cron) или на живом боевом сервере без предупреждения управляющего рестораном.**

### 2. `sync_iiko.py` — Модуль интеграции с iikoCloud API v2
* **Назначение:** Предоставляет функции авторизации (`get_token`) с автоматическим кэшированием токена на 50 минут (`.iiko_token_cache.json`), выполнения запросов к облаку (`post_api`) и метод создания заказов (`create_delivery_order`).
* **Зависимости:** Python 3.10+, стандартная библиотека.
* **Создаёт ли реальный заказ:**
  * При прямом запуске (`python tools/sync_iiko.py`): **НЕТ**, только запрашивает JWT-токен и проверяет связь с сервером.
  * При импорте функции `create_delivery_order(order_data)`: 🚨 **ДА, создаёт заказ в iikoFront.**
* **Безопасный способ запуска:**
  ```bash
  python tools/sync_iiko.py
  ```

### 3. `fetch_iiko_menu.py` — Выгрузка номенклатуры из облака iiko
* **Назначение:** Получает актуальный список категорий и блюд из iikoCloud (`/api/1/nomenclature`) и сохраняет результат в JSON-файл `iiko_nomenclature.json`.
* **Зависимости:** Python 3.10+, стандартная библиотека.
* **Создаёт ли реальный заказ:** ❌ **НЕТ.** Скрипт выполняет исключительно операцию чтения (Read-Only).
* **Безопасный способ запуска:**
  ```bash
  python tools/fetch_iiko_menu.py
  ```
  После выполнения обновляет или создаёт `iiko_nomenclature.json` в корне проекта.

### 4. `test_iiko_endpoints.py` — Комплексная диагностика эндпоинтов iiko
* **Назначение:** Опрашивает диагностические эндпоинты iikoCloud:
  1. `/api/1/organizations` — список доступных ресторанов и их GUID;
  2. `/api/1/terminal_groups` — список кассовых терминалов и их статус;
  3. `/api/2/menu` — внешние меню (при наличии);
  4. `/api/1/stop_lists` — актуальный стоп-лист (блюда на остатке / заблокированные).
* **Зависимости:** Python 3.10+, стандартная библиотека.
* **Создаёт ли реальный заказ:** ❌ **НЕТ.** Полностью безопасный диагностический скрипт.
* **Безопасный способ запуска:**
  ```bash
  python tools/test_iiko_endpoints.py
  ```
