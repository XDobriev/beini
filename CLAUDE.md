# BEINI Restaurant & iikoCloud Integration

Интерактивный веб-сервис и экосистема онлайн-заказов для ресторана интернациональной и авторской кухни **BEINI** (г. Назрань, ул. С. С. Осканова, 21) с прямой интеграцией в кассовую систему **iikoCloud / iikoFront**.

---

## 1. Стек и ключевые файлы

### Фронтенд & Активы:
* `index.html` — основной лендинг и меню доставки (чистый HTML5, нативный CSS, адаптив Mobile First).
* `js/app.js` — логика корзины, фильтрация блюд, модальные окна бронирования, прямая отправка заказов в Go API (`/api/order`, `/api/test-order`).
* `js/menu-data.js` — каталог блюд с реальными UUID номенклатуры iiko (`iikoId`).

### Бэкенд на Golang (FoodTech Integration Gateway):
* `cmd/server/main.go` — основной HTTP-сервер: раздача статики, Graceful Shutdown, роуты `/api/order`, `/api/test-order`, `/api/health`.
* `cmd/test-order/main.go` — консольная утилита для быстрого теста кассы из терминала (`go run ./cmd/test-order`).
* `internal/config/config.go` — загрузка конфигурации и поддержка переменных окружения (12-Factor App).
* `internal/domain/order.go` — доменные сущности заказа, расчет суммы и валидация.
* `internal/iiko/client.go` — потокобезопасный клиент iikoCloud (API v2, двойная блокировка `sync.RWMutex`, кэширование JWT, контекстные таймауты).
* `internal/iiko/dto.go` — строгие DTO структуры iikoCloud API.
* `internal/handler/order_handler.go` — обработчики HTTP-запросов.
* `internal/middleware/middleware.go` — структурированный логгер (`log/slog`), CORS и перехват паник (Recoverer).
* `Dockerfile`, `docker-compose.yml` — multi-stage сборка продакшен-контейнера (~20 МБ).

### Конфигурация & Документация:
* `iiko_config.json` — конфигурационный файл интеграции со всеми боевыми идентификаторами и ключами iiko.
* `TESTING_IIKO_FRIDAY.md` — детальный регламент проведения живого тестирования в ресторане в пятницу.
* `PITCH_BEINI_IIKO.md` — сценарий презентации ценности сайта руководству ресторана.
* `tools/sync_iiko.py`, `tools/test_order.py` — вспомогательные Python-скрипты в каталоге `tools/`.

## 3. Статус интеграции и проверка кассы iikoFront

> **Статус:** ✅ **Живое тестирование в ресторане успешно проведено 30.10.2026.**
> Сквозная цепочка «Сайт -> Go API -> iikoCloud -> касса iikoFront Амины» подтверждена (звук, карточка в доставке, печать чека).

Когда пользователь спрашивает: *«Как протестировать заказ?»* или *«Как сделать тест в пятницу?»*:

### Вариант 1. Через браузер с запущенным Go-сервером (Рекомендуется для презентации):
1. Запустить сервер:
   ```bash
   go run ./cmd/server
   ```
2. Открыть в браузере: `http://localhost:8080`.
3. Открыть служебную страницу `http://localhost:8080/demo` и нажать **«Отправить тестовый заказ»** (или собрать корзину на главной и нажать **«Оформить заказ»**). Тест работает только с localhost либо по токену `TEST_ORDER_TOKEN`.
4. Заказ моментально улетает в iikoCloud и отображается на кассе!

### Вариант 2. Быстрый консольный тест через Go CLI:
```bash
go run ./cmd/test-order
```

### Вариант 3. Тест через Python (запасной вариант):
```bash
python tools/test_order.py
```

### Что проверить на кассе iikoFront в ресторане:
1. **Звуковой сигнал кассы:** звонок входящего интернет-заказа.
2. **Экран терминала:** появление карточки во вкладке **«Доставка»** с именем гостя *«ТЕСТ САЙТА (Хамзат)»*.
3. **Принтер чеков:** автоматическая печать сервисного чека на кухне/баре.
4. **Отмена заказа на кассе:** нажать на заказ в iikoFront -> «Отменить» (причина: Тестирование).

## 5. Фронтенд, дизайн-система и правила Zero-Bloat

* **Философия Subtractive Design:** чистый HTML5 + кастомный CSS на переменных + Vanilla JS. Запрещены runtime Tailwind CDN и внешние UI-библиотеки.
* **Цвета:** фон `--bg: #FAF8F3`, чернила `--ink: #1F3A2B`, акцент `--accent: #A3161A`, границы `--line: #E4DFD3`.
* **Типографика:** `Cormorant` (с `lining-nums` для цифр) + `Golos Text`.
* **Эргономика:** Mobile-first, один брейкпоинт 1024px, тапы >= 44px, шторка `max-height: 90dvh`. Тесты кассы только на `/demo`.
